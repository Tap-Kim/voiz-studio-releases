# Voiz Studio Releases

Public installable builds of **Voiz Studio** for Apple Silicon macOS.

## Install

1. Open the [latest release](https://github.com/Tap-Kim/voiz-studio-releases/releases/latest).
2. Download the **macOS arm64 DMG**.
3. Open the DMG and copy **Voiz Studio.app** to Applications.
4. On first launch, if macOS blocks the unsigned build, Control-click the app → **Open**, or use **System Settings → Privacy & Security → Open Anyway**.

The ZIP is provided for users who prefer the raw app bundle. SHA256 checksums are attached to each release.

Voiz models are not bundled in the installer. Install/configure a supported model in Voiz Studio after installation.

Current public release: **v0.0.25**.
